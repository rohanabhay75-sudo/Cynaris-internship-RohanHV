# Week 3 – Day 4: Looker Studio Dashboard

## Project

Indian Business Sales Analysis Dashboard

## Objective

Build an interactive business dashboard using Google Looker Studio connected to a live Google Sheets data source.

## Tools Used

- Google Looker Studio
- Google Sheets
- Git and GitHub

## Dashboard Features

- Total Revenue KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity Sold KPI
- Average Profit Margin KPI
- Revenue by Region
- Revenue by Category
- Monthly Revenue Trend
- Sales Analysis Table
- Interactive Region, Category and State filters
- Date Range Control
