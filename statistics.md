# Week 4 – Day 1: Descriptive Statistics

## 📌 Project Overview

This project focuses on applying descriptive statistics to analyse and summarise a business dataset using Python. The objective is to understand employee sales performance through statistical calculations and visualisations.

## 🎯 Learning Objective

Apply descriptive statistics to summarise and describe real datasets for business reporting.

## 🛠️ Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Git & GitHub

## 📊 Dataset Description

The project uses a sample employee sales dataset containing:

- Employee names
- Employee sales amounts

The dataset contains 10 employee records.

## 📚 Tasks Completed

### 1. Descriptive Statistics

Calculated the following statistical measures:

- Mean
- Median
- Mode
- Variance
- Standard Deviation

### 2. Frequency Distribution

- Created a histogram.
- Analysed sales frequency.
- Identified the distribution shape.

### 3. Distribution Analysis

Studied three types of distributions:

- Normal Distribution
- Right-Skewed Distribution
- Bimodal Distribution

### 4. Percentiles and Quartiles

Calculated:

- 25th Percentile
- 50th Percentile
- 75th Percentile
- 90th Percentile
- Q1, Q2 and Q3
- Interquartile Range (IQR)

### 5. Box Plot Analysis

- Compared sales performance between Group A and Group B.
- Analysed median and standard deviation.
- Identified potential outliers.

## 📈 Key Business Insights

- Analysed average and median employee sales.
- Identified variation in sales performance.
- Observed right-skewness caused by higher sales values.
- Compared performance across two employee groups.
- Used statistical measures to support business decisions.
