# Week 3 – Day 3: Excel for Analysis

### Project Overview

This project focuses on analysing Indian business sales data using Microsoft Excel. The objective was to clean, organise, analyse, and visualise sales data to identify business performance trends and key performance indicators (KPIs).

### Tools & Technologies

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Slicers
- Conditional Formatting
- Excel Formulas
- Git & GitHub

### Dataset Description

The project uses a sample dataset containing 3,000 sales records.

Key columns include:

- Order ID
- Order Date
- Region
- State and City
- Product and Category
- Customer Segment
- Sales Channel
- Quantity
- Revenue
- Cost
- Profit
- Profit Margin
- Payment Mode
- Order Status

_Note: This is synthetic sample data created for learning and practice._

### Tasks Completed

#### 1. Data Preparation

- Converted raw data into an Excel Table.
- Organised sales records.
- Prepared data for analysis.

#### 2. Data Cleaning Using Power Query

- Imported CSV files.
- Checked and corrected data types.
- Removed duplicate records where appropriate.
- Cleaned and transformed data.

#### 3. Data Combination

- Practised Append Queries.
- Practised Merge Queries.
- Combined sales data with product information.

#### 4. Data Analysis Using PivotTables

- Analysed revenue by region.
- Analysed product-wise sales.
- Calculated total profit.
- Examined quarterly sales performance.
- Analysed profit margins.

#### 5. Data Visualisation

- Created PivotCharts.
- Developed regional sales charts.
- Created category-wise sales charts.
- Analysed quarterly revenue trends.

#### 6. Interactive Dashboard

- Added slicers for Region, Category, Year, and Sales Channel.
- Created KPI cards.
- Arranged charts and visualisations into a dashboard.

#### 7. Conditional Formatting

- Highlighted positive and negative profits.
- Applied data bars to revenue values.
- Highlighted profit margins using colour rules.

#### 8. KPI Analysis

Created four important business KPIs:

- Total Revenue
- Total Profit
- Profit Margin
- Total Orders

#### 9. Dashboard Maintenance

- Practised Refresh All.
- Updated Power Query and PivotTable data.
- Prepared the workbook for presentation.

### Key Learning Outcomes

- Improved Excel data analysis skills.
- Learned data cleaning and transformation using Power Query.
- Gained practical experience with PivotTables and PivotCharts.
- Understood interactive dashboard creation using slicers.
- Learned KPI calculation and conditional formatting.
- Improved business data interpretation and reporting skills.
