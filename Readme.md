# Data Analytics Internship

## 📌 Project Overview

This repository contains my work, tasks, and practical learning activities completed during my Data Analytics Internship.

The main objective of this internship is to develop practical skills in data cleaning, data analysis, visualization, KPI reporting, and business insights using industry-relevant tools.

## 🎯 Internship Objectives

- Develop practical data analytics skills.
- Clean and transform datasets.
- Perform exploratory data analysis.
- Create meaningful KPIs and business reports.
- Build interactive dashboards.
- Document and manage projects using Git and GitHub.

## 🛠️ Tools \& Technologies

- **Microsoft Excel** – Data cleaning, PivotTables, PivotCharts, and analysis.
- **Power Query** – Data transformation and preprocessing.
- **Power BI** – Interactive dashboards and KPI visualization.
- **SQL** – Database querying and data manipulation.
- **Python** – Data analysis and automation.
- **Git \& GitHub** – Version control and project management.

## 📊 Key Activities

1. Data collection and importing datasets.
2. Data cleaning and preprocessing.
3. Handling missing and duplicate values.
4. Combining multiple CSV files.
5. Creating PivotTables and PivotCharts.
6. Building interactive dashboards.
7. Creating KPI measures and calculating performance metrics.
8. Identifying trends and anomalies.
9. Preparing business KPI narratives and reports.
10. Uploading project files and documentation to GitHub.

## 📈 Key Performance Indicators

- Total Revenue
- Total Orders
- Return Rate (%)
- Target Achievement (%)
- Sales Performance
- Business Trends and Anomalies

## 📚 Learning Outcomes

- Improved data cleaning and analytical skills.
- Gained practical experience with Excel and Power BI.
- Learned to create business-focused KPI dashboards.
- Improved understanding of data visualization.
- Developed Git and GitHub version-control skills.
- Improved ability to communicate insights through reports.

Aspiring Data Analyst with a strong foundation in Data Science, Excel, SQL, Python, and Power BI. Interested in transforming raw data into meaningful insights and supporting data-driven business decisions.
